
Behavioral matrix

## Human input and object response

Human input - Object state - Physical output - Linguistic output

## Phase 1
Human input: Unrelated speech.
Object state: Listening
Physical output: Stillness or deceleration 
Linguistic output: None

## Phase 2
Human input: Heat-related speech
Object state: Accumulation
Physical output:  Low airflow	
Linguistic output: None

## Phase 3 
Human input: Continued heat discourse	
Object state: Intensification
Physical output:  Medium airflow	
Linguistic output: None

## Phase 4
Human input: High concentration of thermal references	
Object state: Saturation
Physical output:  Maximum airflow
Linguistic output: None

## Phase 5
Human input: end of heat discourse
Object state: Dissipation 
Physical output:  Gradual deceleration	
Linguistic output: None

## Phase 6 
Human input: Prolonged silence
Object state: Invitation
Physical output:  Stillness
Linguistic output: Spoken heat poetry

## Phase 7 
Human input: Subject approaches	
Object state: Waiting	
Physical output: Stillness
Linguistic output: displayed invitation

## Phase 8
Human input: Human exhalation
Object state: reception
Physical output:  Breath detection
Linguistic output: Poetic acknowledgment

## Phase 9
Human input: Absence of breath	
Object state: Waiting
Physical output:  Stillness
Linguistic output: Repeated invitation

## Phase 10
Human input: Speech before breath is returned
Object state: waiting
Physical output:  Stillness
Linguistic output: Reciprocal request remains active

## Phase 11
Human input: Speech after reciprocal exchange
Object state: Renewal
Physical output:  Responsive airflow
Linguistic output: None


## Computational states

State	-  Function
LISTEN: Recognize speech and regulate airflow.
INVITE: Generate and recite heat poetry.
WAIT_BREATH: Wait for directed human exhalation.
ACK: Acknowledge the breath and reset the interaction.

## Interaction condition

Speech alone does not complete the reciprocal exchange.

The object requires a bodily gesture in the form of human breath before returning to its normal listening state.
